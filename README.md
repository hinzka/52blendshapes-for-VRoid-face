# 52blendshapes-for-VRoid-face

VRoid Studio正式版のVRMモデルを個人で改変したモデルです。
iPhoneの表情トラッキング機能に対応した52個のBlendShapeおよび補助シェイプを含んでいます。

本モデルは「パーフェクトシンク（Perfect Sync）」と呼ばれる仕様に対応しています。

表情の研究と情報共有を目的として作成したデータです。
他のVRoidモデルへBlendShapeを作成・コピーする際の元データとして、自由にお使いください。

男性素体モデルと女性素体モデルがあります。
利用したいモデルをダウンロードしてお使いください。

# English

This model is a personal modification of the VRM models included with the official version of VRoid Studio.

It contains **52 BlendShapes for iPhone facial expression tracking**, as well as additional auxiliary shapes, and supports the specification commonly known as **Perfect Sync**.

This data was created for the purpose of facial expression research and information sharing.
Please feel free to use it as source data when creating or copying BlendShapes to other VRoid models.

Male and female base models are available.
Please download whichever model you would like to use.
